# ISTILE Annuaire

Auteur : Fih Abah Justin

Mini-annuaire des étudiants de niveau 3 de l'ISTILE, réalisé dans le cadre du Mini-TP Modules 1 et 2.
Il comprend une page web responsive (HTML/CSS) et des programmes JavaScript qui traitent des données JSON.
Les données viennent du fichier etudiants.json et d'une API publique de démonstration (dummyjson.com).

## Lancement

```bash
npm start
```
